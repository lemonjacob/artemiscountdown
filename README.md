# Artemis Countdown Clock

I was fell into being super interested in the countdown process and the launch of artemis during both artemis I and II. During artemis 1 I had a much more scuffed version of the website to follow along with the mile stones so using my greater knowlege and codex I upgraded it. Will be back for artemis III whenever that happens

[![Nuxt UI](https://img.shields.io/badge/Made%20with-Nuxt%20UI-00DC82?logo=nuxt&labelColor=020420)](https://ui.nuxt.com)



## Quick Start

```bash [Terminal]
npm create nuxt@latest -- -t ui
```

## Setup

Make sure to install the dependencies:

```bash
pnpm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
pnpm dev
```

## Production

Build the application for production:

```bash
pnpm build
```

Locally preview production build:

```bash
pnpm preview
```

Check out the [deployment documentation](https://nuxt.com/docs/getting-started/deployment) for more information.
